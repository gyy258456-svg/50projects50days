# 《别急着定义自己》— 12秒故事测试

这是新增的独立测试版本，保留V2关键画面、8秒测试及全部旧版本。没有制作23秒完整版，没有调用付费服务。

## 观看

下载 `exports/story-test-12s.mp4`，用系统播放器打开。

下载观看包并解压，双击 `watch.html` 可用浏览器播放实际导出的视频；`index.html` 是可播放、暂停、重播和任意时间定位的实时版本。无需使用右侧网页预览。

## 故事

0–2.5秒：首次公开分享，人物正在表达，话语突然断续，听众看向他。

2.5–4.5秒：“我不擅长表达”的判断从这次事件中形成，线框将这段经历封闭。

4.5–6.5秒：镜头深入，重复出现的仍是同一次讲话卡壳；不是又发生了几次失败。

6.5–9.5秒：空间展开，同一个人在熟悉的朋友面前交谈自然；带着准备稿分享时表达清楚；面对陌生人时仍然紧张。

9.5–12秒：经历按条件与表现进行比较，线条连接的是明确的关系，最后出现“别急着定义自己”与“多经历，也多回看”。

## 实现

人物、话筒、听众、杯子、准备稿和波形均由本地Canvas路径动态绘制。它们没有使用静态PNG背景或生成式插画。事件层通过分块投影映射进入同一三维坐标空间，场景转变由四边形顶点和镜头共同推动；局部人物手势、波形与注意线仍持续运动。

继承8秒版本的调色板、透视基、Hermite镜头路径、确定性时间接口与免费Chromium/FFmpeg导出流程；对本轮12秒的语义事件和比较关系重新制作。本轮为无音轨视觉测试，静音即可看到主要事件。

## 重新导出

`python3 render.py` 导出1920×1080、60fps、12秒、720帧MP4；`python3 verify-playback.py`检查实际浏览器解码、跳转与完整播放。需要当前云环境已经提供的Python Playwright、Pillow、Chromium和FFmpeg。

渲染及播放结果保存到 `exports/qa/`。`exports/storyboard.png`只用于检查与回看，动画不使用这张图片。
