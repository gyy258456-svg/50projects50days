## 工程判断

旧工程可复用确定性逐帧渲染、Chromium截图与FFmpeg编码流程。旧人物、重复楼房、简单步态与白色淡出不适合此项目，需重做。保留全部旧版本，在本目录独立实现。

后续将用可分层的SVG/Canvas场景、人物曲线与局部关节，配合时间驱动的镜头、透视、遮挡和连续门框转场。技术方案的实际表现必须由6秒运动测试检验，不能仅凭静态图片确认“动画质量”。
