# Motion8 参考复核与质量门槛

已实际读取：两个本地上传 MP4 通过 ffprobe 与 FFmpeg 解码。检查全片代表帧、既有每 0.5 秒连续序列，并新抽取 52.3–54.3s 数轴收窄、55.8–57.8s 场景转路线、249.7–251.7s 路径生长的每秒 6 帧序列。未进行音轨审听，不声称实时逐秒观看全片。

## 确认的参考规律

- 参考 1 的庭审空间逐件退场，人物与地面位置保留，三条路由同一落脚点长出。构图不会每一刻都发生镜头推拉。
- 参考 2 的数轴切开后，红色淘汰区首先移开，剩余区间再重映射铺满。因果可读性优先于同时发生的复杂形变。
- 参考 2 的经历路径先画出弧，再让节点沿该弧走。层次依赖弱背景地形、清晰主弧、最亮核心点的亮度层级。
- 文字绝大多数时间维持独立安全区。局部标签不与主图抢焦点。

## 推荐 8 秒时间轴

| 区间 | 可读的单一主动作 | 镜头/层次 |
| --- | --- | --- |
| 0.00–0.45 | 核心点呼吸，两条短自由路径 | 远空间；微推进，不要纯黑开头 |
| 0.45–1.05 | 三标签依序进入并连向核心附近 | 标签 0.12 秒错位；远背景低亮 |
| 1.05–2.15 | 关联线转为封闭边界 | 推进约 15%；最后封口联动标题 |
| 2.15–3.35 | 同六面延伸/翻转成六层切片 | 固定焦距，移动眼点；近层更快 |
| 3.35–4.65 | 同四样本重复，空间实际变窄 | 近层离开视野，远层保留更久 |
| 4.65–5.18 | 核心轨迹被限制，推进减慢 | 窄空间成为唯一视觉重心 |
| 5.18–5.65 | 接触右边界，局部弯折/产生缺口 | 摄影机惯性保持，避免突然反向 |
| 5.65–6.65 | 同边界展开为 2–3 主路径 | 回撤与轻抬高，近远平面分离 |
| 6.65–7.45 | 新节点循分支进入 | 保留原四点；部分连接停在间隙 |
| 7.45–8.00 | 未完成的开放场域保持 | 镜头与主图自然减速，不再新增标题 |

## 复核门槛

- 2.2 秒附近：标题/图形同一时间改变不超过一个主动作；核心点连续；六框顶点顺序无翻转或穿插跳跃。
- 5–6 秒：至少可追踪一条边从闭合变弯再变路径；不可用 opacity 将旧框退场、重新淡入一套网络。
- 透视：焦距固定、镜头 eye-z 与平面真实 z 变化分开；近层投影速度显著高于远层；穿近裁剪面时几何裁剪，不要整体闪退。
- 图形：核心亮度远高于节点和边界；六框最多 1–2 层明显，其余通过亮度建立深度；主要分支不超过三条，避免数据网络HUD。
- 信息：重复四样本在各层位置有有限重新排列；Outward 原四点可辨认，至少约 1/3 新点未连接，没有隐含“已理解完毕”。
- Typography：主图与底字幕分区，三个短标题足够；使用本地 CJK 字体。禁长段文字、微型不可读注释。
- 输出：1080p60 8 秒即 480 帧；后半秒不黑屏/不 fade to black；帧间运动保持可导或自然缓动。

## 工具判断

现有 Canvas 确定性场景、软件投影、FFmpeg 输出能满足本轮，且适合顶点连续形变。HyperFrames/GSAP 可辅助制作时间轴和视频导出，但不应为插件换掉已可验证的架构。必须清楚标注是否实际由 HyperFrames CLI 渲染；仅阅读技能或运行 doctor 不代表它参与成片。
