# 《别急着定义自己》— V2精细化 / 8秒连续测试

这是独立的动画测试版。旧版visual-system-v2、人物插画提案和旧视频全部保留；本次不制作23秒成片，也不发布正式版本。

## 不懂编程也能观看

直接下载 `exports/motion-test-8s.mp4`，用系统播放器打开。

下载完整预览压缩包并解压后，双击 `watch.html` 可在浏览器播放已经渲染的视频；双击 `index.html` 可查看实时图形版本，支持播放、暂停、重播、时间定位。无需安装项目依赖，不依赖右侧内嵌网页预览。

优化后的三张关键帧位于 `exports/01-opening.png`、`exports/02-inward.png`、`exports/03-outward.png`；多时间点分镜位于 `exports/storyboard.png`。

## 同一套图形持续演化

核心光点始终是同一个self-core。Opening的六面从标签关联线逐边形成；随后原来的四个顶点连续移动，六面变为纵深切片。四个经验节点在层间重复，表示原有样本被反复回看。

5–6秒核心靠近最内侧边界，原有边界弯曲、开口并翻转。它们成为向外延伸的路径，原来的样本保留，新样本从空间之外进入。一部分关系建立，另一部分仍没有连接，不把全部经历画成已经理解的网络。

## 镜头与确定性

Canvas不是整幅图片缩放：每个边界顶点和节点有独立三维坐标，镜头具有eye、target、固定焦距与近平面裁剪。近景和远景的投影随镜头位置产生不同变化。摄影机用连续Hermite曲线，几何状态采用具有平滑起止速度的曲线。

`renderFrame(time)`直接还原任意0–8秒画面，不依赖滚动事件或随机运动。固定细纹用于抑制渐变条带，没有随机粒子喷射。`sample-data.js`继承V2的固定经验节点身份。

## 输出与工具

目标并验收的输出：1920×1080、60fps、8秒、480帧、H.264 MP4，无音轨。本轮重点验证画面与运动，不添加未经确认的配音、音乐或付费服务。

HyperFrames相关技能与本地开源CLI可用并已检查；此次实际动画及视频渲染使用原生Canvas、Chromium和FFmpeg，HyperFrames没有参与时间轴或MP4渲染。保留现有有效流程，是为了直接控制透视和坐标形变，不是将静态PNG放入时间轴。

## 重新导出（供开发者）

在本目录运行 `python3 render.py --stills-only` 检查关键帧，运行 `python3 render.py` 导出视频与质量记录。需要本地Python Playwright、Pillow、Chromium和FFmpeg；这些工具已在当前云环境提供。详细结果以本次导出的QA报告为准。
