# 8 秒测试最终视频复核

实际输入：`motion-test-8s/exports/motion-test-8s.mp4`，ffprobe 确认 H.264、1920×1080、60fps、480 帧、8.000 秒，3,890,303 字节。

FFmpeg 从真实编码 MP4 解码得到帧 131/132/133、299/300、312/330/336/345、360/361、479；帧板 `final-encoded/encoded-review-board.png`。与对应渲染源 PNG 比较，平均 RGB 绝对误差约 1.0–1.65/255，编码帧与源帧匹配；没有错帧、代码预览与 MP4 不一致的问题。量化差异详情见 `final-encoded/comparison.json`。

视觉结果：

- 2.2 秒邻近三帧：立方体、核心和样本延续，没有替换式闪切。
- 5.0–6.0 秒：核心向右触边，右边变暖受力，边界弯曲后逐层形成缺口，转为开放路径；因果可追踪。
- 6.0 与 6.0167 秒：邻帧内容连续，没有旋转/投影突变。
- 7.983 秒：提高摄影机后展开空间比 pilot 有更清晰的层次；主路径、薄弱关系与空心未整合点区别明确。没有全部连成网络造成错误暗示。
- 中文“别急着定义自己”“向内探索”“向外探索”“同一组经历，反复回看。”“经历变多，不等于理解自动发生。”正确，文字安全区完整。标题与主要结构分区，字幕无截断或图形明显遮挡。
- 最终帧保持开放结构，没有结束黑屏。

当前没有阻止这轮 8 秒测试交付的具体缺陷。此复核以实际视频解码帧、密集关键转场序列和源帧对比为依据，不声称实时审听整段音轨，也不将这段试片等同最终 20–25 秒成片的验收。
