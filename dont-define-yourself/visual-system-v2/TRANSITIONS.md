# 三张关键画面的连续转换

本轮只导出静态PNG。以下是下一阶段待验证的动画设计，不是已完成的运动效果。

## 01 → 02：边界由框定变为嵌套

1. 中心暖金光点 `self-core` 始终保留，表示尚未被概括完的自己。
2. 开场“内向、理性、不擅长表达”是示意性身份判断，关联线从这些判断向中心包拢，形成透明边界。
3. 组成边界的六个四边形 `boundary-0…5` 保持同一顶点顺序：立方体的六个面依次翻转为嵌套认知切片。每个对象都拥有四个顶点，可直接做坐标插值。
4. 镜头与切片尺寸分开控制：镜头逐渐推近，实际可见范围同时缩小，让“看得更近，但样本更少”的对比可见。
5. 早期四个节点 `sample-0…3` 留在中心。灰色回声是同一节点的复制显示，不代表新经验。经验线回到原有节点，表达内循环。

## 02 → 03：同一切片展开为世界的信息场

1. 最外层切片打开一条边，六张切片绕各自轴翻转并扩展，成为第三张中的空间网格。不是换上另一张场景图。
2. 镜头先沿原有光路走，再后撤、略抬高；原有四个样本保持身份和相邻关系，可追踪它们从中心移向更大的场域。
3. 新经验节点 `sample-4…47` 从边界之外渐次进入；存在于同一固定节点池，而不是每帧随机生成。
4. 同一条 `experience-path` 从内循环变为向外分叉。三个状态的主折线均为六个顶点；边界四边形和折线均能保持拓扑一致。
5. 外部网络中部分连接采用虚线、空心节点与未闭合轮廓，表示“获得经历”与“形成理解”之间还有整理过程。暖金表示注意到的经历，冷灰结构表示尚待连接的关系。

## 后续结论段（本轮未制作）

将其中一条外部经验线返回核心，在中心重新连接旧样本，再向外延伸；往返才构成更新。结尾应表达“去体验，回来看，再出发”，不能让向外网络被误读为自动完成理解。

## HyperFrames的角色

在关键画面确认后，优先采用本地HyperFrames+GSAP：可寻址暂停时间轴驱动顶点插值和镜头容器，Studio检查连续运动，再导出6秒1080p60测试。SVG坐标插值自行编写，不假设任意路径自动形变或使用收费MorphSVG服务。
