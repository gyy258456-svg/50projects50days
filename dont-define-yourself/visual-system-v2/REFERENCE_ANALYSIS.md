## 构图

参考1用暗舞台、水平地面、长阴影、琥珀光环、光锥与微小人物符号。人物服务于人与世界、社会剧本和选择的关系，没有人物面部插画。

参考2用近黑粒子场、冷青细线、金色光点、数轴与网络地形。主要信息图形居于视觉中心，边缘微标签和底部字幕提供解释；深度主要由亮度、光晕与尺度建立。

## 镜头与实际运动

不能说参考是全程快速推拉：许多段落保留稳定构图，让图形本身持续变化。

- 参考1约11–13秒：标题缩入角落，发光圆盘保留，地面与人物被揭示。
- 约56–59秒：庭审结构逐级退出，同一人物位置生长出三条路线，路线随后放大。
- 约78–80秒：球沿斜坡下落；约82–85秒，画面靠近人物与斜坡。
- 参考2约25–28秒：粒子汇聚成标题，横向光脉冲运动。
- 约52–56秒：数轴反复二分，丢弃一半变红，剩余区间重新缩放，二进制位累计。
- 约151–153秒：青色椭圆逐渐围住被噪声破坏的文本，红色块与波形继续变化。
- 约249–253秒：弧线在空间地形上生长，金色节点沿弧线移动。

这些帧序列能够确认图形位置、比例和结构变化，不能仅据此断言使用了真实3D摄影机。

## 信息可视化

参考1把社会期待变为重复人群、选择变为路径、持续反抗变为人/球/斜坡的循环。参考2把猜测变为范围缩小、噪声变为文字受损、冗余变为保护边界、陌生经历变为路径上的光点。关键在于结构与概念的对应，不在于堆装饰。

## 图形转场

参考1复用圆盘、地面、人物与路线；路线保留并成为下一段斜坡。参考2复用光点、细线、粒子、环和网路；光先画出关系，节点随后进入位置。它们不是一组独立海报之间的淡化。

## 文字排版节奏

中文以宋体/明朝体气质的短句为主，底部一到两行字幕；关键词才占较大面积。参考1用暖橙强调“反抗”等语义重点；参考2以金色副标题、图形附近小标签和公式建立层级。文本会显隐、打字或随语义亮起，不像网页正文滚动。
