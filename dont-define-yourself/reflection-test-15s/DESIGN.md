# 比较与反思 · 15秒独立测试

根据60秒叙事V1第四至第六幕，重新剪排为独立15秒预览。保留旧V2、8秒和12秒文件。

0–4秒：同一人物在交流会与陌生小组中两次试图开口、收回手、后退。门/窗、桌面和便笺连续变形，地面及人物保留；两条后退轨迹走过相同范围（上下轻微错位，便于辨认两次行为）。共同条件是陌生且没有准备，而不是地点本身。

4–9秒：同一房间向侧面转开，朋友和准备后的两层实时事件展开。镜头先跟随朋友交谈，再进入准备后的分享，再回到陌生场合。准备后的表达有停顿，查看提纲后继续，波形完成。三个场合形成可比较的情境。

9–13秒：“我不擅长表达”作为待检验的判断出现。陌生场合中的事实与感受分别标注，另外两次真实表现进入对照。连接来自实际声音与经历，不是随机网络；封闭的标签边界向外打开。

13–15秒：人物和三种经历保留，边界成为开放的比较轴。结尾“先比较，再判断”，没有将负面绝对判断换成正面绝对判断。

实现沿用本地确定性Canvas时间轴、同一人物曲线路径与真正三维摄影机。新增WebGL透视平面映射，消除旧仿射三角网格的接缝。GPU只映射每帧重新绘制的事件层；没有静态插画轮播。背景只有固定低对比纹理。镜头用三次Hermite样条，图形用五次缓动，所有任意时间点可直接还原。

HyperFrames相关技能可访问，但本测试没有调用HyperFrames渲染、GSAP或付费服务；复用现有本地免费渲染流程。

这段是静音视觉测试，用于评审故事能否靠画面表达。不是60秒正式成片，也没有加入合成旁白。
